### Sobre mim

Tenho 22 anos e trabalho com **Planejamento e Controle da Produção** numa indústria de autopeças. Comecei como aprendiz em 2023 e hoje sou analista pleno.

Gosto de transformar dados da fábrica em decisão. Uso **Python, automação e IA** para tirar o trabalho manual do caminho, para que o time de PCP e a liderança vejam o que importa: carga das máquinas, aderência ao sequenciamento, atrasos e WIP.

- 🏭 Planejamento de capacidade, sequenciamento e carga máquina
- 🐍 Python para dados e automação (pandas, openpyxl, RPA)
- 📊 Indicadores e dashboards: Power BI, HTML/JS e 3D com Three.js
- 🤖 IA aplicada: assistentes sobre os indicadores, agentes com n8n e Claude
- 🧩 Key user na implantação do Siemens Opcenter APS

### Projetos em destaque

| Projeto | O que faz | Tecnologias |
|---|---|---|
| **Hub de Indicadores da Produção** | Um app único com os indicadores da fábrica: Programado × Realizado, Hora x Hora, Carga Máquina, Controle de Horas, WIP e Fábrica 3D. Tem visão por perfil (gerência, coordenador, líder e turno) e um assistente de IA que responde sobre os dados. | Python · JavaScript · Three.js · Cloudflare Workers · Workers AI |
| **Automação da Coleta de Dados de Produção** | Um robô que, a cada 30 minutos, coleta os apontamentos do ERP, trata os dados, atualiza todos os indicadores e publica o app. Alertas automáticos vão para o Teams. | Python · RPA · Agendador do Windows · Teams |
| **Análise de Carga Máquina** | Compara a demanda (OPs firmes + MRP) com a capacidade por máquina, célula e B.U. Considera calendário por B.U, feriados e sábados, e mostra fotos do relatório lado a lado para enxergar o que entrou, saiu ou foi antecipado. | Python · pandas · JavaScript |
| **Indicador de WIP** | Mostra as peças paradas entre processos, há quantos dias estão paradas e quanto do WIP está sequenciado. | Python · JavaScript |
| **Implantação do Opcenter APS (key user)** | Construção, testes e validação do sequenciamento junto ao time de projetos até o go-live. | Siemens Opcenter APS |

> Os sistemas acima rodam na empresa e usam dados internos, por isso o código não é público. Os detalhes de cada projeto estão no repositório [portfolio-pcp](https://github.com/guicollalincoln-glitch/portfolio-pcp).
